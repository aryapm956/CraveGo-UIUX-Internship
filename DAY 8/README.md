# Day 8 – Product Details, Cart & Checkout Screens

## Overview

Today's work focused on designing the core purchasing experience of the CraveGo food delivery application. The objective was to create intuitive and user-friendly screens that allow users to view food details, manage their shopping cart, and complete the checkout process efficiently.

## Objective

The primary goal of this task was to design the screens involved in the ordering process while maintaining consistency with the existing design system.



### Product Details

The Product Details screen provides users with complete information about a selected food item.

It includes:

- Food image
- Food name
- Price
- Rating
- Description
- Quantity selector
- Add to Cart button

This screen helps users make informed purchasing decisions before adding an item to their cart.

### Cart

The Cart screen allows users to review the items they have selected.

Features include:

- List of selected food items
- Quantity controls
- Individual item prices
- Total order amount
- Checkout button

The layout is designed to make order review simple and convenient.

### Checkout

The Checkout screen guides users through the final ordering process.

It includes:

- Delivery address
- Payment method selection
- Order summary
- Total amount
- Place Order button

The design focuses on creating a smooth and secure checkout experience.

## Design Consistency

The screens follow the design system created earlier by maintaining consistent colors, typography, spacing, buttons, icons, and reusable components.

## User Flow

Product Details → Add to Cart → Cart → Checkout → Order Confirmation

This sequence ensures a simple and intuitive purchasing experience.

## Key Learning

This task helped me understand how users interact with shopping and checkout interfaces. I learned the importance of organizing information clearly, minimizing unnecessary steps, and maintaining consistency across multiple screens.

## Outcome

Successfully completed the Product Details, Cart, and Checkout screens, preparing the application for the final ordering and order confirmation experience.
