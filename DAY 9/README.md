# Day 9 – Profile & User Account Screens

## Overview

Today's work focused on completing the user account section of the CraveGo food delivery application. The objective was to design screens that allow users to manage their personal information, saved addresses, payment methods, favorite items, previous orders, and application settings while maintaining a consistent and user-friendly interface.

## Objective

The goal of this task was to design the account-related features that support user management and improve the overall usability of the application.

## Screens Designed

### Profile

The Profile screen acts as the central hub for managing user information and account-related options.

Features include:

- User profile information
- My Orders
- Saved Addresses
- Payment Methods
- Settings
- Logout

### Saved Addresses

This screen allows users to manage delivery locations.

Features:

- Home address
- Work address
- Add new address
- Edit and remove existing addresses

### Payment Methods

Users can manage their preferred payment options.

Features:

- UPI
- Credit/Debit Card
- Cash on Delivery
- Add new payment method

### My Orders

This screen provides access to order history and current orders.

Features:

- Ongoing orders
- Completed orders
- Cancelled orders
- Order details

### Favorites

Users can quickly access their favorite restaurants and food items for faster ordering.

### Settings

The Settings screen allows users to customize their application experience.

Features include:

- Notifications
- Dark Mode
- Language
- Privacy
- Help & Support
- About

### Contact Us

Designed to help users reach customer support through different communication channels.

## Design Consistency

All screens follow the existing design system by maintaining consistent typography, color palette, spacing, buttons, icons, and reusable components.

## User Flow

Profile → Orders / Favorites / Saved Addresses / Payment Methods / Settings → Update Information

The navigation was designed to keep account management simple and accessible.

## Key Learning

Designing account management screens helped me understand the importance of organizing user information in a structured and intuitive way. I also learned how reusable UI components improve consistency across multiple screens.

## Outcome

Successfully completed the Profile and User Account section of the application, bringing the overall UI closer to completion.
