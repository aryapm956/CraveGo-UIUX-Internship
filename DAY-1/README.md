# 📖 Overview

Today marked the beginning of my UI/UX Design Internship at Codomax Digital Solutions.

The objective of Day 1 was to build a strong foundation before starting the design process. I installed and configured Figma, explored its workspace and tools, and created a new project for my Food Delivery Mobile Application, **CraveGo**.

I also studied the fundamental concepts of User Interface (UI) and User Experience (UX), along with essential design principles such as consistency, alignment, hierarchy, contrast, spacing, and usability. These concepts form the basis for creating intuitive and user-centered digital products.

This project will continue through the complete UI/UX design process, including user research, wireframing, design systems, high-fidelity UI design, prototyping, and responsive layouts.

# 📚 Key Concepts Learned

### User Interface (UI)

User Interface focuses on the visual appearance of an application, including colors, typography, icons, buttons, layouts, and interactive elements.

### User Experience (UX)

User Experience focuses on how users interact with the application, ensuring that navigation is simple, intuitive, and user-friendly.

### Design Principles

- Consistency
- Alignment
- Visual Hierarchy
- Contrast
- Spacing
- Usability
