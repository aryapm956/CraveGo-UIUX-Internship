# Day 6 – High-Fidelity UI Design

## Overview

This stage focused on transforming the earlier low-fidelity wireframes into polished, high-fidelity interface designs.

The main goal was to apply the design system created in the previous stage and turn the basic wireframe structure into a more realistic and visually consistent mobile interface.

## Objective

The objectives of this task were to:

- Convert wireframes into high-fidelity UI screens
- Apply the established color and typography system
- Maintain consistent spacing and alignment
- Use reusable UI components
- Improve visual hierarchy and readability
- Create a clean and consistent mobile interface

## Screens Designed

### 1. Splash Screen

Designed the opening screen with the application branding and a simple visual layout to provide a clear starting point for the user.

### 2. Login Screen

Designed the login interface with:

- Welcome message
- Email input
- Password input
- Login button
- Create account option

The layout was kept simple and easy to understand while following the established visual guidelines.

## Design Approach

The high-fidelity screens were developed by building on the wireframes created earlier.

Instead of changing the original structure completely, I focused on improving the visual appearance by applying:

- Defined color palette
- Typography hierarchy
- Button styles
- Input field styles
- Spacing guidelines
- Corner radius
- Alignment
- Visual hierarchy

This helped maintain consistency between the different stages of the design process.

## From Wireframe to High-Fidelity UI

The earlier wireframes provided the basic structure and placement of the elements.

In this stage, those structures were developed into more realistic interfaces by introducing actual typography, colors, components, spacing, and branding.

This process helped me understand how a low-fidelity concept can gradually develop into a polished user interface.

## Key Learning

This task helped me understand the practical process of converting wireframes into high-fidelity designs.

I also learned that maintaining consistency across typography, colors, spacing, buttons, and other components is important when designing multiple screens for the same application.

## Outcome

The initial high-fidelity screens were completed and prepared for the next stage of the design process.
