## UI/UX Design Internship – Codomax Digital Solutions

**Project:** CraveGo – Food Delivery Mobile Application  
**Day:** 5  
**Task:** Design System

---

## 📌 Overview

For Day 5 of my UI/UX Design Internship, I worked on creating the **Design System for CraveGo**, my Food Delivery Mobile Application.

After completing the user research, user journey, user flow, and low-fidelity wireframes, I focused on defining the visual style and reusable elements that will be followed throughout the application.

The purpose of creating this design system is to keep the interface **consistent, organized, clear, and easy to use** while designing the remaining screens.

---

## 🎯 What I Worked On

I created a complete design system covering:

- Color Palette
- Typography
- Buttons
- Input Fields
- Cards
- Icons
- Reusable UI Components
- Bottom Navigation
- Spacing & Design Rules
- Design Principles

---

## 🎨 1. Color Palette

I defined the main colors that will be used throughout the CraveGo application.

| Type | Color |
|---|---|
| Primary | `#FFC83D` |
| Secondary | `#FFF8E8` |
| Background | `#FFFCF5` |
| Text | `#2B2118` |
| Secondary Text | `#6F6256` |
| Success | `#4CAF50` |
| Warning | `#E85D5D` |
| Border | `#E8DCC8` |

The color palette gives CraveGo a warm and food-focused visual identity while keeping the interface clean and readable.

## 🔘 3. Buttons

I created three button states for different actions in the application:

### Primary Button
Used for important actions such as **Add to Cart**.

### Secondary Button
Used for supporting actions such as **View Menu**.

### Disabled Button
Used when an action is temporarily unavailable.

The buttons follow the same visual style throughout the application to maintain consistency.

## 📏 9. Spacing & Design Rules

I defined a spacing scale to maintain proper alignment and consistent spacing between elements.

### Spacing Scale

- 8px
- 16px
- 24px
- 32px

### Corner Radius

- 8px
- 12px
- 16px
- 20px

These rules will help maintain a consistent layout when creating the high-fidelity screens.

---

## 💡 Design Principles

I followed four main principles while creating the CraveGo design system:

### Consistency
Using the same fonts, colors, buttons, and spacing throughout the application.

### Hierarchy
Making important information more prominent so users can understand the interface easily.

### Clarity
Keeping the interface simple and easy to understand.

### Accessibility
Using readable text and sufficient contrast to make the interface easier to use.

---

## 🛠️ Tool Used

**Figma**

## 📚 What I Learned

Through this task, I learned how a design system helps organize the visual elements of a digital product.

I understood the importance of defining colors, typography, components, spacing, and design rules before designing multiple screens. Having these elements prepared makes it easier to maintain consistency and avoid designing the same component repeatedly.

The design system created today will be used as the foundation for the next stage of my CraveGo project.
