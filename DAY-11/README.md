Day 11 – Responsive Design
Overview

On Day 11, I worked on creating responsive layouts for my CraveGo – Food Delivery Mobile Application by adapting the existing mobile screens into tablet and desktop versions.

The goal of this task was to understand how UI elements should adjust across different screen sizes while maintaining consistency, usability, and visual hierarchy.

Responsive design ensures that users get a smooth experience regardless of the device they use.

Task Completed
Created tablet and desktop versions of key application screens
Adapted layouts according to different screen sizes
Maintained consistent spacing, typography, and design elements
Improved alignment and content organization for larger screens
Ensured navigation components work effectively across devices
Applied responsive design principles to maintain a seamless user experience
