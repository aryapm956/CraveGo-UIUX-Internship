## 📖 Project Overview

**CraveGo** is a modern and user-friendly **Food Delivery Mobile Application UI/UX** designed using **Figma**. The application focuses on providing a seamless food ordering experience with an attractive interface, intuitive navigation, and a complete ordering workflow.

This project was created as part of my **UI/UX Design Internship at Codomax Digital Solutions**, where I designed the application from research and wireframes to a fully interactive prototype.
