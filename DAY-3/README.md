# 📖 Introduction

The third day of the internship focused on designing the User Journey and User Flow for the CraveGo Food Delivery Mobile Application.

Before creating wireframes or high-fidelity interfaces, it is important to define how users move through the application and interact with different features. A well-planned user flow minimizes confusion, improves navigation, and ensures users can complete their goals efficiently.

This activity transformed the research conducted on Day 2 into a structured interaction flow, providing a clear blueprint for the application's navigation and screen sequence.

---

# 🎯 Objectives

- Design the complete user journey for ordering food.
- Create a user flow representing every major interaction.
- Organize the application's navigation hierarchy.
- Identify the sequence of screens before wireframing.
- Improve usability through logical navigation planning.

---

# 👤 User Journey

The user journey describes the overall experience of a customer while using the application.

The journey begins when the user opens the application and logs into their account. After successfully accessing the home screen, the user searches for food or browses restaurant categories, selects a preferred restaurant, explores menu items, adds products to the cart, completes checkout, makes a secure payment, receives an order confirmation, and finally tracks the delivery until the order reaches its destination.

This journey helps visualize every stage of the customer's interaction with the application and identifies opportunities to improve the user experience.

---

# 🔄 User Flow

The user flow represents the step-by-step navigation between screens.

```

Splash Screen

↓

Login / Sign Up

↓

Home Screen

↓

Browse Categories / Search Food

↓

Restaurant Details

↓

Food Details

↓

Add to Cart

↓

Cart

↓

Checkout

↓

Payment

↓

Order Confirmation

↓

Track Order

↓

Order Delivered

```

This structured flow ensures that users can navigate the application efficiently while minimizing unnecessary steps.

---

# 🗂 Navigation Structure

The application's navigation hierarchy was also planned to organize different sections before designing the interface.

- Food Details
