# Day 7 – Home & Restaurant Screens

## Overview

This stage focused on designing the main browsing experience of the food delivery application.

The goal was to create the screens through which users can discover food, explore categories, browse restaurants, and view available food items.

## Objective

The main objectives of this task were to:

- Design the main Home screen
- Create food categories for quick discovery
- Design restaurant listing and restaurant detail screens
- Maintain consistency with the established design system
- Make food discovery simple and easy to navigate

## Screens Designed

### Home Screen

The Home screen was designed as the main starting point for users.

It includes:

- User greeting
- Search bar
- Food categories
- Popular restaurants
- Recommended food items
- Food cards
- Bottom navigation

The layout is organized so that frequently used options and food recommendations can be accessed quickly.

### Categories

Food categories were added to make browsing easier.

The screen includes categories such as:

- Burgers
- Pizza
- Desserts
- Fried Chicken
- Drinks

The category section provides a quick way for users to discover food based on their preferences.

### Restaurant Screens

Restaurant screens were designed to provide more detailed information about individual restaurants.

Each screen includes:

- Restaurant image
- Restaurant name
- Rating
- Delivery information
- Restaurant type
- Popular food items
- Food images
- Prices
- Add-to-cart actions
- View Cart option

Multiple restaurant screens were designed to maintain a consistent structure while displaying different restaurant and food information.

## Design Approach

The screens were created using the visual system established in the previous stages.

I maintained consistency in:

- Colors
- Typography
- Spacing
- Cards
- Buttons
- Icons
- Corner radius
- Bottom navigation
- Food item presentation

The main focus was on making the browsing experience clear while keeping the interface visually consistent.

## User Experience

The Home screen acts as the starting point for food discovery.

A typical interaction can be understood as:

Home → Select Category → Explore Restaurant → View Food Items → Add Food to Cart

This structure allows users to move from discovering food to selecting a restaurant and choosing items with minimal navigation.

## Key Learning

This task helped me understand how a home screen can organize a large amount of content without making the interface difficult to use.

I also learned how reusable cards and components can be applied across different restaurant screens while maintaining a consistent visual language.

## Outcome

The Home, Categories, and Restaurant screens were completed and prepared for the next stage of the application design.
