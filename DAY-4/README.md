# 🚀 Day 4 – Low-Fidelity Wireframes

## 📅 Internship Details

**Organization:** Codomax Digital Solutions

**Project:** CraveGo – Food Delivery Mobile Application

**Task:** Day 4 – Design Low-Fidelity Wireframes

---

# 📖 Introduction

The fourth day of the UI/UX internship focused on creating low-fidelity wireframes for the CraveGo Food Delivery Mobile Application.

Based on the user research, user journey, and user flow prepared during the previous days, the next step was to convert those ideas into structured screen layouts. Rather than focusing on colors, typography, or visual aesthetics, low-fidelity wireframes emphasize layout, content organization, navigation, and interaction flow.

Wireframing is one of the most important stages of the UI/UX design process because it allows designers to validate ideas, improve usability, and identify potential issues before moving into detailed visual design.

---

# 🎯 Objectives

- Create low-fidelity wireframes for the core application screens.
- Establish a consistent layout and navigation structure.
- Organize content according to user needs.
- Prepare the project for the high-fidelity UI design stage.

---

# 📱 Wireframes Created

The following wireframes were designed during this stage:

- Splash Screen
- Login Screen
- Home Screen
- Food Details Screen
- Cart Screen
- Checkout Screen
- Order Confirmation Screen
- Profile Screen
- Contact Us Screen
- Settings Screen
- Favorites Screen

---

# ✨ Design Approach

The wireframes were intentionally designed with minimal visual styling to focus entirely on functionality and usability.

Key considerations included:

- Simple and intuitive navigation
- Logical content hierarchy
- Clear call-to-action placement
- Easy accessibility of important features
- Consistent layout across all screens

---

# 🛠️ Tools Used

- Figma
- Low-Fidelity Wireframing
- User Flow Planning
- UX Design Principles

---

# 📚 Learning Outcome

Designing low-fidelity wireframes helped me understand how ideas evolve into structured interfaces. By concentrating on layout and functionality before visual styling, I gained a deeper understanding of screen hierarchy, navigation flow, and user-centered design. This stage provides a strong foundation for creating polished high-fidelity interfaces in the next phase of the project.
